# 🚀 How to Run AI Interview System

## ✅ Quick Start (Easiest Method)

### Option 1: Double-Click Method
1. **Navigate to the "AI Interview" folder**
2. **Double-click `START_HERE.bat`**
3. **Wait for "Server running" message**
4. **Open browser and go to: http://localhost:3000/simple_fixed.html**

### Option 2: Manual Method
1. **Open Command Prompt or PowerShell**
   - Press `Windows + R`
   - Type `cmd` or `powershell`
   - Press Enter

2. **Navigate to the project folder**
   ```bash
   cd "C:\Users\91998\Desktop\rey\AI Interview"
   ```

3. **Start the server**
   ```bash
   node simple-server.js
   ```

4. **Open your browser**
   - Go to: **http://localhost:3000/simple_fixed.html**

## 🔧 Troubleshooting

### If you see "Server already running":
- **Good news!** The server is already running
- Just open your browser and go to the URL

### If you see "node is not recognized":
- You need to install Node.js
- Download from: https://nodejs.org/
- Install and restart your computer

### If browser shows blank page:
- Try: http://localhost:3000/simple_fixed.html (with /simple_fixed.html)
- Clear browser cache (Ctrl + F5)
- Try incognito/private mode

### If port 3000 is busy:
- Close other applications using port 3000
- Or restart your computer
